# 《君がいた季節 FR》简体中文补丁（rUGP 5.95）

> 2011 重制版《君がいた季節 -FR-》的运行时文本汉化补丁。**不修改游戏任何原始文件**，全程运行时替换。
> 当前版本：**v1.19.2**（2026-11-20）· 正文 44,138 条 · 名牌 · 48 条路线选项 · F8 中/日切换

---

## ⚠️ 使用前必读（重要）

1. **需要你自己的正版游戏。** 本仓库只包含翻译数据与补丁程序，**不包含游戏本体、不包含任何游戏原始数据文件**。
2. **仅适配**「君がいた季節 -FR-」2011 重制版 rUGP 5.95.08K 整合包（含特典）。
   其他版本（2000 年原版、其他平台/移植版等）引擎偏移不同，**不保证可用，甚至可能崩溃**。
3. 本补丁仅供**个人学习交流**使用，请在下载后 24 小时内删除，并支持正版。
4. 补丁以 DLL 代理方式注入（SHFolder.dll → cnpatch.dll），**部分杀毒软件可能误报**。
   请将游戏目录加入白名单，或使用「原版启动.cmd」以无补丁方式运行。
5. **不要**把补丁里的任何文件改名/移到别处，**不要**用补丁文件覆盖游戏原始文件。
   卸载时只需删除补丁文件，游戏本体不受影响。
6. 游戏存档位于 `%USERPROFILE%\Documents\age\君がいた季節FR\Vmreg\`。
   补丁**不会**主动读写存档；但「正常退出游戏」时引擎会回写已读标记 `gdb.uuc`，
   如果不想改变已读状态，请用任务管理器结束 `rugp.exe`（普通玩家无需在意）。

## 功能

- 游戏正文、人物名牌（如【万里花】【正树】）全量简体中文（44,138 条，运行时替换）。
- 48 条路线分歧选项汉化（含各角色线关键选项）。
- **F8** 随时在中文 / 日文原文之间切换（对之后显示的文本生效）。
- 读档后新出现的文本同样汉化；原版模式（不加载补丁）随时可用。
- v1.18 修复：**存档备注乱码**——新保存的存档，读档界面卡片备注显示为可读日文原文。
- v1.19.2 修复：**短句（≤32 字节）在回味/正文仍显示日文**——v1.18 的 storefix 会把 24 字节短句的回味节点内联缓冲改回日文；本版让 storefix 跳过短句（长句存档备注不受影响）。同时补齐 **29 条译文缺失的右引号**。
- v1.19.1 修复：**路线选项显示错字**——v1.19 重建隧道码后没同步重建选项表，48 条选项全部错字；
  已用同一套安全码判定重新编码并逐条回译校验（48/48）。
- v1.19 修复：**名牌/正文个别汉字被画成别的字**（回味里【まりか】→【６りか】、正文 ま→６、き→喘 等），
  并让**回味（バックログ）显示中文**（此前整页日文）。

## 安装

从 [Releases](../../releases) 下载最新 zip，解压后把以下内容放进**游戏根目录**（与 `Kimiita.exe` 同一层）：

```
SHFolder.dll
cnpatch\                （整个文件夹）
汉化版启动.cmd
原版启动.cmd
说明.txt
验证记录.txt            （可选）
```

完成。游戏原始文件一个都没有被改动。

## 启动

| 方式 | 效果 |
| --- | --- |
| 双击 `汉化版启动.cmd` | 中文补丁模式（等价于直接双击 `Kimiita.exe`，只要 SHFolder.dll 在位） |
| 双击 `原版启动.cmd` | 日文原版模式（设置 `CNPATCH_DISABLE=1`，不加载补丁） |

启动时若弹出 rUGP 提示框，点「忽略(I)」或「否(N)」即可；标题画面加载约 60–90 秒。

## 已知限制（不是 bug，先看这里）

- **引擎 UI 文字仍是日文**：标题菜单（最初から/続きから/プレミア/コンフィグ/終了）、
  存/读档界面标题与按钮、设置画面、确认框、启动免责声明——这些由引擎内部字体直接绘制，
  不在文本替换范围内。正文与名牌不受影响。
- **存档界面卡片备注**：v1.18 起新存档备注为可读日文；**v1.17 及更早版本保存的旧存档**
  备注已经以乱码形式写进文件，无法在不修改存档的前提下修复（读档后重新保存一次即可覆盖）。
- **读档瞬间**：存档时停留在屏幕上的那一句会显示日文（引擎直接恢复存档文本），
  向前推进一句后恢复中文。
- **特典 DLC「告白」**：正文（台词与旁白，约 3,392 条）已在文本表内，实测显示中文；
  特典入口菜单与游戏内 HUD（通信/状況解析/MAP 等）为引擎直接绘制，仍是日文。
- 图片 / CG / 影片内的文字不汉化（按需求只替换文本层）。
- 若极少数字符显示为缺字或方框，请反馈该句原文（可开 `misslog=1` 记录未命中文本）。

## 配置（`cnpatch\config.ini`）

```ini
enabled=1      ; 1=启用汉化，0=关闭（等价原版）
log=0          ; 1=写 cnpatch\cnpatch.log（排查问题用）
hotkey=0x77    ; 0x77=F8；0x00 表示禁用热键
misslog=0      ; 1=记录未命中的原文（反馈缺译时用）
storefix=1     ; v1.18：存档备注修复（保持开启）
keepzh=1       ; v1.19：显示缓冲保留中文，让回味显示中文（保持开启）
```

约定：

- 原句里的 `0x03`（引擎的停顿分隔符）显示为空格，末尾的 `0x01` 结束符已去掉；
- 台词原文可能跨行，已统一转成字面量 `\n`，保证一条记录占一行；
- 中文里的生僻字通过隧道码表还原成正常 Unicode 字符，可直接阅读与检索。

```bash

python tools/dump_bilingual.py --dir cnpatch --choice-only -o bilingual/choice.tsv  # 选项
```

## 技术原理（简述）

1. **文本层**：在 Vm60 的文本取指针函数（+0x79B55）挂钩，把原文（Shift-JIS）按表替换为中文；
   中文用「隧道码 + 宋体字形钩子」显示，保证中文字形正常且不与日文原生码冲突。
2. **数据层**：全部译文在 `cnpatch_txt.bin` 中；只替换「比原文短、能原位放下」的句子，绝不越界。
3. **注入**：借游戏启动时加载的 SHFolder.dll 作代理，自动加载 `cnpatch\cnpatch.dll`，
   无需外部注入工具；`CNPATCH_DISABLE=1` 即原版模式。
4. **存档备注**：引擎会把绘制过的文本复制进自己的文本池，存档 comment 取的就是这份副本。
   补丁在每句绘制后把副本还原为日文原文，因此存档写入的是可读日文（详见 docs/）。

## 源码与构建

源码在 `src/`（C + GNU as）。

```bash
# 编译器：i686-w64-mingw32-gcc（MinGW32）
i686-w64-mingw32-gcc -O2 -shared -o cnpatch.dll \
  cnpatch.c choice.c hookstub2.S hookstub3.S \
  -lgdi32 -luser32 -ladvapi32 -Wl,--enable-stdcall-fixup

# 代理 DLL
i686-w64-mingw32-gcc -O2 -shared -o SHFolder.dll \
  proxy/shfolder_proxy.c proxy/shfolder_proxy.def -Wl,--enable-stdcall-fixup
```

翻译表由 `src/build_patch.py` / `src/build_choice.py` 生成（需要对应的语料/译文文件，未包含在本仓库）。
