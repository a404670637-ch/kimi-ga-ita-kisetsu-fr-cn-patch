## 二、三个 bug

### 1. 名牌/正文个别汉字被画成别的字（v1.19 修复）
`【まりか】`→`【６りか】`、`ま`→`６`、`き`→`喘`、`睦`→`朦`、`月`→`灾`、`優`→`一`。
根因：`build_rmap()` 用 `MultiByteToWideChar(932, 隧道码)` 的 Unicode 当键，而 `GetGlyphOutlineA` 收到的是
原始 SJIS 码；隧道码 0xE49C 的 Unicode 恰好是「ま」的 SJIS 码 0x82DC。旧表 868 个码位撞车、370 个真出现在语料。
修复：构建期 `_safe_code()` 三条约束 + 重生成 namemap（175 组字色）。详见 `docs/BACKLOG_GLYPH_FIX_20261120.md`。

### 2. 回味整页日文（v1.19 修复）
v1.18 的 storefix 把**显示缓冲**也还原成日文，而回味读的就是它。
修复：`keepzh=1`（显示缓冲 + 每行显示节点保留中文，存档备注用的计数串仍还原）。
已实测确认**不影响存档备注修复**（保存预览不读那个中文节点）——见 `docs/SAVE_UI_TEXT_FINDINGS.md` 附录。

### 3. 48 条路线选项全错字（v1.19.1 修复，静默回归）
v1.19 重建隧道编号后没同步重建选项表 → 48/48 条解码全乱（如「蛙咱碳髓鵐拷拷看熄」）。
修复：`t_fix_choice.py` 用同一套安全码判定重编 + 回译校验 48/48。见验证记录「二十四」。
